# Government Grievance Redressal Portal

A web-based Government Grievance Redressal Portal developed using Python, Flask, and SQLite.

## Features

* Citizen Registration
* Citizen Login
* Submit Grievance
* View My Grievances
* Admin Login
* Admin Dashboard
* Update Grievance Status
* Track Complaint Status

## Technologies Used

* Python
* Flask
* SQLite
* HTML
* CSS

## Project Structure

* app.py
* database.db
* templates/
* README.md

## Purpose
